# Titleify Pro 🧪

> Breaking Bad Title & Animated Intro Creator with authentic theme audio, periodic element badges, and volumetric smoke.

## Features
- **100% Offline & Web-Based**: Powered by HTML5 Canvas and Web Audio API.
- **Authentic Soundtrack**: Synced with the iconic 17.1-second Breaking Bad opening theme.
- **Multi-Phase Intro Sequence**:
  - Phase 1: 3D floating chemical formulas (C10H15N, 149.24, meth)
  - Phase 2: 3D periodic table flythrough grid with camera zooms
  - Phase 3: Authentic Title Reveal with chemical badges and rolling volumetric cooking smoke
  - Phase 4: Subtitle / Credits screen with chemical badge & cinematic fadeout
- **Export Options**:
  - High-Definition PNG / JPEG Image
  - 1080p MP4 / WebM Video with audio
  - Standalone Python CLI script (export_video.py)

## Deploying on Vercel
Deploying Titleify Pro on Vercel is instant:

### Option 1: Vercel CLI
Run in this folder:
`ash
npx vercel
`
Follow the simple prompts, and your site will be live in seconds!

### Option 2: GitHub + Vercel Dashboard
1. Push this repository to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new) and import the repository.
3. Click **Deploy** (no build settings needed, it's ready out of the box).
